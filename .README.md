# Descripción del proyecto

Este proyecto consiste en un programa de consola desarrollado en C# para registrar y mostrar información de productos de la tienda TecnoPunto.

El programa utiliza clases, objetos, propiedades, constructores y métodos, aplicando los conceptos básicos de programación orientada a objetos.

# Datos de entrada

 Código del producto.
 Nombre del producto.
 Precio del producto.
 Cantidad disponible.

# Procesamiento

El programa valida que el nombre no esté vacío, que el precio sea mayor que cero y que la cantidad no sea negativa.

También calcula automáticamente el valor total de cada producto multiplicando su precio por la cantidad disponible.

# Datos de salida

El programa muestra el código, nombre, precio, cantidad y valor total de cada producto registrado.
